# AquaVisionX — remove A/B/C/D prefixes from explanation

Remove the option-letter prefixes (A., B., C., D.) from the **"Why the other options are wrong"** section and the **summary table** in AquaVisionX explanations, and show the option text itself in bold instead. Don't touch the Concept, "Why the correct answer is right", or any other part.

## What changes

### 1. Gemini prompt — `SOLVE_SYSTEM` in `src/lib/aquavisionx.functions.ts` (line 171–172)

Change the explanation format instruction so Gemini outputs the **option text** (bolded) instead of a letter prefix:

**Before:**
```
**Why the other options are wrong**
- **A.** one clear sentence with the specific reason
- **B.** ...
- **C.** ...
- **D.** ...
```

**After:**
```
**Why the other options are wrong**
- **<option text>** — one clear sentence with the specific reason
(list ONLY the wrong options, each starting with its own text in bold, no letter prefix)
```

Change the summary_table instruction to say the Option column must contain the **option text only** (no letter prefix):
```
| Option | Verdict | One-line reason |
|---|---|---|
| Histiocytes | ✗ | ... |
| T-lymphocytes | ✓ | ... |
```

This fixes all **new** explanations generated by AquaVisionX.

### 2. Display-side cleanup — `src/components/ExplanationPanel.tsx`

Add a small transform applied **only** to the `wrong` and `summary` section bodies (not to concept, correct, or any other section), so already-imported explanations are also cleaned up without re-running:

- **Wrong section bullets:** strip the `**A.**` / `**B.**` prefix — regex like `/^\s*[-•]\s*\*\*[A-Z]\.\*\*\s*/gm` → `- ` (removes the bolded letter prefix, leaves the rest of the line intact).
- **Summary table cells:** strip the leading letter in the first column — regex like `/\|\s*[A-Z]\.\s+/g` → `| ` (removes `A. ` / `B. ` etc. from the Option column).

This is a fallback/safety net — it also catches any case where Gemini still emits a letter despite the prompt change.

## What stays the same

- Concept section, "Why the correct answer is right" section, answer-letter logic, import flow, JSON schema, batch mechanics — all untouched.
- Other tools (Jarvis Batch v2, Patch iPad ProX) are not touched; their prompts keep the old format. The display-side cleanup is harmless to them (it only strips letter prefixes from wrong/summary sections, which is a visual improvement, not a behavioral change).

## Testing

Re-run one AquaVisionX paper through Stage 2 and confirm:
- The "Why the other options are wrong" bullets start with the option text in bold, no letter.
- The summary table's Option column shows option text only, no letter.
- Concept and "correct answer" sections are unchanged.
- An old already-imported explanation (with letter prefixes) also renders without letters after the change.
